#OpenBlep

ESP32-S3 adapter firmwares for BLE game controllers like the Joy-Con 2, M64 Pro, and Gamestation Gamepad controllers.

**Heavily** inspired by Switch 2 Connect: https://github.com/TommyWabg/Switch2Connect/
